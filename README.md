# Financial Fraud Detection

## About
A Machine Learning based project that detects potentially fraudulent financial transactions using Python and Random Forest.

## Technologies
- Python
- Pandas
- Scikit-learn
- SMOTE
- Random Forest
- Streamlit

## Features
- Data analysis and visualization
- Fraud vs Safe transaction analysis
- Machine Learning fraud prediction
- Interactive Streamlit dashboard

## Dataset
Fraud Detection.xlsx

## Model Performance
- Accuracy: 99.41%
- Precision: 66.67%
- Recall: 28.57%
- F1 Score: 40%

## How to Run

Install dependencies:

pip install pandas scikit-learn imbalanced-learn openpyxl joblib streamlit

Run model:

python model.py

Run dashboard:

python -m streamlit run app.py
